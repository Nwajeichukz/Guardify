# custom-auth-manager

A custom authentication manager library for Spring Security.

## Get it from JitPack

[![](https://jitpack.io/v/your-github-/Nwajeichukz/custom-auth-manager.svg)](https://jitpack.io/#/Nwajeichukz/custom-auth-manager)

### Maven

```xml
	<repositories>
		<repository>
			<id>jitpack.io</id>

		</repository>
	</repositories>

		<dependency>
			<groupId>com.github.Nwajeichukz</groupId>
			<artifactId>Guardify</artifactId>
